# Changelog

## 1.2.3 — 2026-10-30

- Fixed: the stock panel sometimes did not appear when pointing at a Dispatch Port or a Raven
- Fixed: the stock panel was drawn over the end-of-run result screen

## 1.2.2 — 2026-10-08

- Fixed for game v0.29.1: releasing the mouse button was not detected, so Dispatch Ports could fail to place
- Fixed for game v0.29.1: dragging a relay chain stopped after the first segment
- If a future game update breaks the mod, the mod turns itself off instead of stopping the game from starting

## 1.2.1 — 2026-09-29

- The left-panel toggle button is gone: game v0.29 added its own Map information tab (F1), which made it redundant. The left panels now start right below the Stock button

## 1.2.0 — 2026-09-13

- A Dispatch Port that still holds items stays when its Raven is removed (`Keep a dispatch port that still holds items`)

## 1.1.1 — 2026-09-13

- The wand panel (name, cost, target) shows in map view while a wand skill is selected
- Auto placement bends around unowned land
- A single click far away lays the whole line
- Dropping the line on a crafter snaps to its input more reliably

## 1.1.0 — 2026-09-07

- Auto placement: click beyond the range and the line is laid for you
- Map view moves in half steps; redeploy from a boundary lands on the boundary

## 1.0.2 — 2026-09-07

- The last Dispatch Port faces the way the game's snap decides
- Rocks, buildings and unowned land along the way are stepped back from
- Hold to keep moving in map view

## 1.0.1 — 2026-09-01

- Thunderstore page rewritten as bullet points

## 1.0.0 — 2026-09-01

- First release: drag to lay relay lines, retarget a Raven, stock display, map view tweaks
