# LWF Raven QoL

A QoL mod for Delivery Ravens in **Lazy Witch's Factory**.

## Drag placement

- Place a Raven, drag, release
- "Dispatch Port + Raven" pairs line up at maximum carrying range

![Drag placement](https://raw.githubusercontent.com/KiyonakaNata/lwf-raven-qol/main/img/chain-drag.webp)

## Retarget a Raven

- Point at a Raven → `Toggle Dispatch Port Setup` (default `Tab`)
- Click / share / drag a new line
- The old Dispatch Port stays

![Retargeting](https://raw.githubusercontent.com/KiyonakaNata/lwf-raven-qol/main/img/retarget.webp)

## See what's inside

- Hover a Raven or Dispatch Port → icon × count

![Hover stock panel](https://raw.githubusercontent.com/KiyonakaNata/lwf-raven-qol/main/img/stock-hover.png)

## Map view

- Top left: redeploy Momoko / stock overlay / left-panel toggle
- Control hints and sponsors are hidden

![Map view buttons](https://raw.githubusercontent.com/KiyonakaNata/lwf-raven-qol/main/img/mapview.webp)

Settings: `BepInEx/config/kiyonakanata.lwfravenqol.cfg`. Full documentation: [GitHub](https://github.com/KiyonakaNata/lwf-raven-qol).
